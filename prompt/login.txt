Update my Vue.js E-note application so that `App.vue` handles Supabase Authentication and controls access to the Login and Dashboard pages.

### Project Context

This is an E-note/document management application using:

* Vue 3
* Vite
* Vue Router
* Supabase
* Supabase Auth
* Supabase Database
* Supabase Storage

The application already has a document/upload page and an existing `documents` table in Supabase. Do not remove or break the existing document functionality.

### Main Goal

Modify `App.vue` so the application uses Supabase Auth to determine whether the user is logged in.

The behavior should be:

1. When the user is NOT authenticated:

   * Show the Login page.
   * Prevent access to protected pages such as Dashboard and Upload Document.
   * If the user manually navigates to a protected route, redirect them to `/login`.

2. When the user IS authenticated:

   * Redirect them to `/dashboard`.
   * Allow access to Dashboard and other authenticated pages.
   * Display the authenticated user's email/name where appropriate.
   * Provide a Logout button.
   * When Logout is clicked, call `supabase.auth.signOut()` and redirect to `/login`.

### Supabase Client

Use the existing Supabase client configuration.

If the project already has something similar to:

```js
import { supabase } from '@/lib/supabase'
```

reuse it instead of creating another Supabase client.

Do NOT expose the Supabase `service_role` key in the frontend. Only use the public anon/publishable key.

### Authentication State

Use:

```js
supabase.auth.getSession()
```

when the application starts to determine the current session.

Also listen for authentication changes using:

```js
supabase.auth.onAuthStateChange(...)
```

The application should react immediately when the user logs in or logs out.

Handle these states:

* Loading authentication state
* Authenticated
* Unauthenticated

Do not briefly display the Dashboard before Supabase finishes checking the session.

### Dashboard

Create a modern E-note Dashboard.

The Dashboard should show:

* Welcome message using the authenticated user's name/email
* Total documents
* Recent documents
* Upload Document button
* Logout button
* Navigation/sidebar

The dashboard should retrieve only documents belonging to the currently authenticated user.

Use:

```js
const { data: { user } } = await supabase.auth.getUser()
```

Then query the `documents` table using the authenticated user's ID.

Assume the `documents` table has a `user_id` column that references the authenticated Supabase user.

Example:

```js
const { data, error } = await supabase
  .from('documents')
  .select('*')
  .eq('user_id', user.id)
  .order('created_at', { ascending: false })
```

Do not retrieve another user's documents.

Do not allow a user to manually specify another `user_id`.
